## Screens and behavior retained from the full brief

- Browse: stable artwork ordering, distinct missing-art placeholders, restored card/focus, explicit Shows/Movies selection, small protected Parents action; no mixed shelves, search, cast wall, recommendation feeds or trailers.
- Titles: Next/Shuffle only for a show, Again after ordered finale; one movie Play/Resume/Play again action and progress indicator; parent-only Start over. Unavailable or ambiguous episode sets require deliberate recovery.
- Player: Select HUD, normal remote Play/Pause, paused focusable timeline, Back overlay/title behavior, next picture/countdown/Stop, show end card, movie return without autoplay.
- Parents: last-browsed-show season/episode thumbnails, independent Play once and Set Next here, scoped resets with confirmation, session one/two/continuous, optional speech preview respecting VoiceOver, audio/captions, connection/help, PIN change/recovery.
- Exceptions: neutral launch loading; empty-category escape; unavailable item; missing cursor; stream reconnect; expired token and library/account change; corrupted state and storage failure.
- Release: core and HTTP tests, actual SwiftUI view permutations, real remote simulator checkpoints, signed Release simulator build and observed fixture exclusion, reproducible setup/recovery/rollback docs, and restricted-account playback evidence. Child observation and physical-device family pilot are explicitly for the user's evaluation, not silently counted as automated passes.

## Evaluation scorecard

Record successful/failed starts, stalls, time to first frame, pause/seek/resume error, transport method, focus mistakes and parent rescues. Proposed targets are ten representative starts, warm-LAN median <= 3 seconds, and four of five unassisted child starts after one demonstration. These are targets, not measured results. Any forbidden-item leak blocks release regardless of playback scores.
