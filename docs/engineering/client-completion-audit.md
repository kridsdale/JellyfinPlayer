## Composition and extension

Both platform App initializers call configure before constructing their body/opening owned storage. StorageComposition supplies native credential storage and localized account names; library code resolves neither Factory nor a current application session. The tvOS root constructs KidsAppModel with KidsAccountHost and KidsPlaybackSessionFactory and supplies KidsPlaybackPresentation. The model orchestrates the exact curated libraries, account leases, artwork/persistence and session owner. Player rendering/native track UI stay in app composition, native resource implementations stay in VLC/MPV/NativePlayback, and bound network/report implementations stay in their owners.

A new feature should first use the existing domain/query/lifetime owner and add adjacent tests. Add a library only for a distinct responsibility with justified dependency edges, then update the manifest policy and public/source review. Supply current account/settings/native implementation through a port or captured snapshot. Keep selection/focus/navigation and OS presentation in the app; do not restore an aggregate facade or a package for every file.

Kids continues to select VLC with queue nil. tvOS socket command observation returns before subscription. Catalogue and artwork admission do not widen beyond the exact verified account/library/item identities. Immutable DTO/result values and UIKit view/image contracts are intentional API representations; native player or Jellyfin mutable implementations are private owners.

## Actor and startup contracts

- KidsAccountHost publishes identity synchronously on the main actor. Admission/Scope and the app host adapter use that explicit same-turn contract; the model's own subscription additionally receives on DispatchQueue.main.
- Artwork memory warnings and value-only notification readers receive on DispatchQueue.main before a main-actor assertion. Raw OS notification payloads are not transferred into the UI reader.
- EPG and offset observation use adjacent main-thread guards and foreign-task actor hops, weak native references and generation/membership checks. The actual current Foundation KVO callback is escaping **Sendable**, so the direct EPG callback does not inherit the registering actor; the offset handler is explicitly nonisolated. Actual UIKit delivery remains unexecuted.
- Private CoreStoreBootstrap contains the sole preconcurrency import and early global logger write. StorageLoggingStartupGate admits one installation, rejects repeated/late writes and freezes before DataStack construction. Both original fake startup orderings remain covered; no real database/global logger is opened during this audit.
- PreferencesView's hosting controller is main-actor; preference callbacks enqueue main-queue updates through a weak box. Native command descriptors carry actor-qualified Sendable actions. The orientation swizzle is a once-initialized UIKit ownership detail. The public iOS/tvOS surfaces and all macro expansion/validation bodies are reviewed; real UIKit execution remains held.
