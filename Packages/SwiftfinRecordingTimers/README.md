# SwiftfinRecordingTimers

Owns current-program resolution, scheduled/series timer lookup, recording
template fallback, create/cancel/update requests and recordability policy.
An immutable item/user and authenticated executor bind every async stage;
permission and time are injected without factories or app settings.
App adapters retain UI action state, notifications and snapshot publication.
Commands are tested only through synthetic senders; no server/media writes.
